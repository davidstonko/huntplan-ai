==============================================================================
KEY IMPLEMENTATION DETAILS
==============================================================================

Universal Link Flow:
  1. User shares: shareCampInvite('Hunt Camp', 'ABC123')
  2. iOS share sheet shows link: https://davidstonko.github.io/.../join/ABC123
  3. Recipient taps link on iOS
  4. iOS checks AASA at davidstonko.github.io/.well-known/...
  5. iOS verifies app entitlements match TEAM_ID
  6. iOS opens app directly (no web view)
  7. deepLinkService parses invite code
  8. navigates to DeerCampScreen with autoJoin=true

Custom URL Scheme Fallback:
  1. join.html loads
  2. Extracts ?camp=ABC123 from URL
  3. Attempts: window.location.href = 'huntmaryland://join/ABC123'
  4. If app opens: browser hidden, fallback doesn't trigger
  5. If app not installed: timeout shows App Store fallback
