# Apple App Site Association (AASA) — Deployment Notes

This file lives at `website/.well-known/apple-app-site-association` and
must be served at:

    https://davidstonko.github.io/huntmaryland-site/.well-known/apple-app-site-association

Apple's Universal Links subsystem fetches this URL on app install + every
~24 hours thereafter. When a user taps a link matching one of the
declared `components`, iOS routes the URL to the installed app instead
of Safari.

## Deploy

1. Copy `website/.well-known/apple-app-site-association` to the
   GitHub Pages repo at `davidstonko.github.io/huntmaryland-site`.
2. Confirm it's served with `Content-Type: application/json` and NO
   redirect — GitHub Pages serves static files directly which is
   correct.
3. Verify with:
       curl -I https://davidstonko.github.io/huntmaryland-site/.well-known/apple-app-site-association
   Expect 200 OK, content-type text/plain or application/json. Apple
   accepts both as long as the body is valid JSON.
4. After deploy, wait 24h for Apple's CDN cache to refresh, OR
   uninstall/reinstall the app to force a fresh fetch.

## Validate the JSON before deploy

    cat website/.well-known/apple-app-site-association | python3 -c 'import sys,json; json.load(sys.stdin); print("valid")'

## Field reference

- `appIDs` — `<TeamID>.<BundleID>` format. Our team ID is
  `BAFL96ZCUU` and the bundle ID is `com.davidstonko.huntmaryland`.
- `components` — path patterns the OS routes to the app. We claim:
  - `/huntmaryland-site/join/*` (current Deer Camp + Honey Hole
    share URLs generated by `deepLinkService.generateShareLink()`)
  - `/join/*` (future short-form URLs once we activate
    `mdhuntfishoutdoors.com`)

## Pairing app side

The app side is wired in `ios/HuntPlanAI/Info.plist` via the
`com.apple.developer.associated-domains` entitlement, which must list:

    applinks:davidstonko.github.io

The runtime URL handling lives in `src/services/deepLinkRouter.ts`
which now parses both `mdhuntfishoutdoors.com/i/{code}` AND the
legacy GitHub Pages `huntmaryland-site/join/{code}` format (added
2026-04-27 to fix the deep-link domain BLOCKER caught in the audit).
