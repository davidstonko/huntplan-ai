# Archived planning and delivery docs

Everything in this folder was moved out of the repo root on 2026-09-18 during the App Review 5.6 dead-code cleanup. These are historical build plans, delivery notes, audits and session summaries whose subject matter has either shipped, been superseded, or been deleted from the codebase (for example the WatermelonDB sync layer, camp intelligence service, export service, waypoint picker, analytics pipeline, state packs and gear-commerce wizard were all removed as unreachable in the same cleanup). They are kept for provenance only and are not maintained; nothing in `src/` depends on them. The authoritative, still-current docs remain at the repo root: `README.md`, `CLAUDE.md`, `PROJECT_STATUS.md`, `ARCHITECTURE.md`, `BUILD.md`, `DEPLOY.md`, and the release / App Review notes for the current version.
