**Status:** 2026-04-26

## Executive Summary

The four curated gear lists show strong foundational work, particularly **Fly Fishing (Gunpowder)** with 26 David-verified picks. However, three critical gaps limit conversion:

1. **Pricing-tier hierarchy is inverted in most categories** — high-AOV items front-load the list, discouraging casual browsers. Budget entry points belong first.
2. **Order optimization missing** — items are organized by subcategory, not by likelihood to convert. No "must-see" items get pinned.
3. **Gap analysis reveals 15–20 high-volume SKUs missing entirely** (e.g., no trail runners in hiking; no basic spinning combo in fishing). These are scroll-stopping, high-commission opportunities.
4. **Chat integration (per monetization plan) will be ineffective without clean hook categories** — vague "flies" and "rods" don't map to search intent.

**Bottom line:** Fly Fishing (Gunpowder) is ready to monetize as-is. The other three categories need restructuring: reorder by price tier, fill gaps, and add sub-style buckets. This audit includes a concrete 4-week test plan with weekly hypothesis variations.

## Section 3: Hierarchy & Structure Recommendations

### Fly Fishing — SubStyle Expansion

**Current subStyle values:** `'euro' | 'conventional' | 'both'`

**Recommended expansion:**
```typescript
subStyle?: 
  | 'euro'           // Euro nymphing (thin lines, indicator rigs)
  | 'conventional'   // Standard fly casting (dries, streamers)
  | 'streamer'       // Large flies, aggressive presentation
  | 'dry-fly'        // Small dries, emergent hatches
  | 'midge'          // Tiny #18-24 patterns
  | 'both'           // Works in multiple sub-styles
```

**Rationale:** Users shopping "Euro nymphing" don't want suggestions for dry-fly reels. Breaking Gunpowder into 5 sub-categories lets the chat ("What fly for Gunpowder?") surface precise suggestions instead of generic "here are all 26 items."

**Mapping exercise:**
| Item | Current | Proposed |
|---|---|---|
| Patagonia Atom Sling | both | both (universal) |
| Rio Premier Gold (WF5F) | conventional | conventional (standard casting) |
| RIO Euro Nymph Line (FIPS) | euro | euro (specific to method) |
| Zebra Midge (#18-20) | both | midge (fits size category) |
| Chubby Chernobyl (#10-14) | conventional | dry-fly + streamer indicator |

### Whitetail Hunting — Platform Split

**Current:** Only saddle hunting.

**Recommended split:**
```typescript
type WhitetailHuntingStyle = 
  | 'saddle'        // Tethrd-based mobile hunting
  | 'treestand'     // Climbing or hang-on stands
  | 'ground-blind'  // Layout/enclosed blinds
  | 'all'           // Works for all platforms
```

**Why:** Ground-blind hunters don't need Tethrd platforms. Adding the field reveals which items are platform-agnostic (boots, clothing, calls, optics) vs specialized (saddle system, climbing sticks, ground-blind windows).

## Section 5: Weekly Experimentation Plan

### Framework

**Objective:** Maximize CTR (taps/shown) + RPM (impressions → revenue).

**Measurement:**
- **CTR = gear_pick_tapped / gear_pick_shown** (target: > 5%, baseline: ~2–3%)
- **RPM = total impressions × commission rate** (varies by category 1–5%)

**Test cadence:** 1 hypothesis per week, run concurrent A/B splits by category.

---

### Week 1: Entry-Tier Dominance

**Hypothesis:** Reordering items from premium-first to budget-first increases CTR by 15–20%.

**Test setup:**
- **Control:** Fishing Bass (current order: Abu Garcia Revo $130 leads)
- **Variant A:** Fishing Bass reordered (Ugly Stik Spinning $50–80 leads, Abu Revo moves to position 4)
- **Run length:** 7 days
- **Sample:** All users who view Bass/Freshwater category

**Expected outcome:** Variant A shows 15–20% higher CTR (more entry clicks, more upsell to mid-tier)

**Success metric:** CTR(A) - CTR(Control) > 10 percentage points

**If wins:** Roll out reordering to Hunting Optics, Camping Ultralight. Mark as pattern.

**If loses:** Keep control, pivot to Week 2.

---

**Hypothesis:** Adding 3-word context phrase ("by David" or "bestseller" or "MD bestseller") increases CTR by 8–12%.

**Test setup:**

### Week 5: Chat Integration — Soft Launch
